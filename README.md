# Meridiano Armazém: centro logístico em 3D

Site de uma página em Three.js. Ao rolar, a câmera caminha do portão neon até a doca de um armazém logístico, passando por porta-paletes, empilhadeiras, contêineres e caminhões.

As marcas são fictícias. Este é um site de demonstração.

**Site no ar:** https://sah123campos.github.io/armazem-3d/

## Como abrir

Abra `index.html` no navegador. É preciso estar conectado à internet, porque o Three.js e as fontes vêm de CDN.

## Tecnologia

- Three.js r128
- Texturas geradas em canvas, sem arquivos de imagem
- HTML, CSS e JavaScript puros, sem build
